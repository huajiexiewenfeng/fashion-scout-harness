# 款集多站浏览器采集版本机包

Windows x64，普通用户可写的较短目录，如 `D:\FashionScout`；包根的完整路径最多100字符，支持中文和空格。完整解压并由 Codex 安装随包的款集 Skill、绑定这个目录后，日常只说“打开款集”：首次自动离线准备并打开认证页面，以后复用已准备的安装。

无需安装系统Python、编辑JSON、复制密钥或选择数据路径。准备使用包内固定CPython和锁定依赖，完整包可离线完成；不会启动巡检。打开入口可恢复此前已接受的已收到文件处理，不创建新巡检。首次打开为空库。

## 在Codex对话采集

在 Codex 说“看看新款”“开始巡检”“继续上次巡检”“导出收藏”或“停止款集”。Codex 按明确范围读取正常网页、保存可观察图片并报告进度，无需用户复制链接、图片、JSON 或凭据。新电脑只确认一次本包位置；Skill 安装和绑定由 Codex 代办。

**采集期间保持Codex运行与浏览器连接可用。** 暂停后在对话中明确“继续上次巡检”，沿同Run继续；不自动生成替代巡检。新款、收藏、图集和导出使用本机页面；已完整接收的文件由独立Worker校验归档，导出和维护也可继续。

本版本采集请在Codex对话发起；网页“开始巡检”按钮仍为旧方式，暂不用于本版本浏览器采集。

业务库、收藏、素材及会话信息存于本目录的 `data`；Python与依赖存于 `.local`。保留整个目录，不在运行时移动或覆盖它。停止只核对并停止本包身份，不按端口杀进程。默认8765，若被其它程序占用会明确拒绝；请保留提示并由开发者处理，不随意强杀程序或改旧库配置。

支持 Futario、RIHOAS 和 SimpleRetro，每次浏览器巡检选择一个站点。新款默认展示已存有效图片的款式，缺图款不会生成空卡；收藏和排除状态保留。已实际验证 Futario 采样20款、89张图库图片，结果 partial；另两站的本机真实巡检仍待验证。日期、完整 product.images 及原像素仍未知，不宣称全站覆盖。本包不含这些运行数据、商品图片或凭据。导出/备份 partial 表示不完整；本机同盘备份不防磁盘损坏。

过长路径、损坏/缺失文件会拒绝准备或打开。路径限制用于避开当前Windows环境的长路径失败，底层任意长路径支持尚未实现。准备失败时保留日志和 `data`，完整重新解压到一个新的较短目录再准备；不要删除或覆盖原 `data`。本候选不自动迁移旧库、升级旧安装或卸载。删除不需要的空测试副本前先停止它；有业务数据的目录由用户自行决定保留与备份。

ZIP摘要由随包交付记录提供；内部 `manifest.json`记录每个输入文件摘要。摘要用于发现缺失/变化，不是数字签名。自有MIT许可和依赖原许可文件在 `licenses`，CPython及其随附组件许可也保留在运行时压缩包和该目录。

完整七份 Skill 资源随包保存，ZIP 本身不会安装个人 Skill。给 Codex 的详细定位见 [运行定位](PACKAGE-CONTEXT.zh-CN.md)。01/02/03 三个 cmd 是备用入口。整个 Codex 退出后来源采集暂停，真正新电脑/系统重启/休眠/物理断电与实际人工省时仍需后续现场验证。
