# 分阶段路线图

> 日期：2026-10-06。当前仅完成初始文档整理；以下实现阶段均未开始，不表示承诺交付日期。

## 阶段 0：收敛架构与验证样本站点

目标：确认来源网站实际能提供什么，再确定首批支持范围。

- 选择少量不同类型站点，覆盖结构化数据、普通页面以及需要浏览器解析的情况。
- 核对商品标识、分页、时间字段、图片范围与原始尺寸可验证性。
- 区分近期发布、首次发现、未知日期候选，预览首次采集规模。
- 确定范围上限、限速、未知日期处理方式及磁盘预算。
- 选择后端、前端、浏览器工具和 Windows 进程启动方式。

退出条件：每个样本站点有可访问性、覆盖范围和限制记录；初始执行参数明确，不以单个成功请求证明全站适配。

## 阶段 1：本地采集与管理闭环

目标：在页面完成一次真实、可追溯的手动巡检。

- Web 服务与独立 Worker。
- SQLite 业务模型和持久化任务队列。
- 站点配置、选站点、时间窗口、手动开始巡检。
- 分层任务状态、有限重试、取消、心跳与中断恢复。
- 商品发现、图片下载、校验、归档和缩略图。
- Dashboard、任务详情、商品图片库。
- 人工分类、标签、候选和收藏。
- 文件核验、磁盘余量提示及选定素材 ZIP 导出。

退出条件：[架构文档的第一版完成标准](architecture.zh-CN.md#13-第一版完成标准)逐项具有实际证据。文档完成、程序实现、样本站点验证和全部目标站点支持分别记录。

## 阶段 2：Skill 与来源扩展

目标：增加对话入口，扩大站点覆盖，并保留统一状态与统计口径。

- Skill 的巡检、查询、重试、检索和导出能力。
- 验证页面和 Skill 调用同一业务接口、生成一致任务记录。
- 按需求增加站点适配器，每站记录能力与已知限制。
- 飞书结果同步、失败恢复和幂等映射。
- 增强备份、维护和适配器回归样本。

退出条件：Skill 不依赖对话记忆恢复任务；新增站点有独立验证结果；飞书失败不引起重复采集。

## 阶段 3：按使用反馈扩展

以下是可选方向，需要单独确定范围后再实施：

- 可配置定时采集，默认仍由用户主动开启。
- AI 商品分类建议、人工确认和质量评估。
- 相似商品或相似图片检索，不自动合并来源身份。
- 存储目录迁移与更完善的备份恢复。
- 服务器部署、多人使用、本地同步程序与权限设计。

服务器保存成功不代表用户电脑已经收到文件；若进入服务器方案，本地同步需回报下载、校验和本地分类状态。

## 实施原则

先验证一条完整业务链路，再增加站点和智能功能。对每个阶段分别记录设计、实现、验证与交付状态。当前仓库无安装命令、可运行示例或已发布应用，后续实现完成后再补充对应说明。
