## 配置与日常最短用法

固定解释器 `E:\github-workspace\fashion-scout-harness\.venv\Scripts\python.exe`，工作目录该仓库。未安装环境时另按 T1 README 一次性安装；本次没有执行生产安装/配置。默认根仍由 T1 决定，自选绝对根则所有命令统一附 `--data-root`。

1. 一次性受控 setup.json 为 `{"port":8765}` → `python -m fashion_scout.client configure --json-input setup.json`。
2. 日常受控 empty.json 为 `{}` → `request ensure`（必要时）→ `request new` / `request favorites` / `request latest` / `request open`，每条均附 `--json-input empty.json`。
3. 明确开始时 start.json 为 `{"new_intent":true}` 或含 overrides.window_days → `request start --json-input start.json`。
4. 响应丢失用 `request intents --json-input empty.json`，模型从列表定位意图，把返回 intent_id 写入 resume.json，调用 `request resume --json-input resume.json`。不要重新 start。

详细字段与错误处理见 Skill 的 references/commands.md；README 仅最小增加实测用法。未修改 pyproject/锁文件，客户端模块随现有包发现规则进入 wheel；Skill 作为仓库目录交付，未声称已进入 wheel 或已全局启用。
